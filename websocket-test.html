🔐 Authentication & Connection

📖 How to get a valid token:
1. Send a POST request to /auth/login with your credentials
2. Copy the access_token from the response
3. Paste it in the field above

Example using curl:
curl -X POST http://localhost:8000/auth/login -H "Content-Type: application/json" -d '{"email":"user@example.com","password":"password"}'

📢 Alerts Namespace

ℹ️ About Alerts

  • Purpose: Receive notifications about new reports and SOS alerts
  • Access: All authenticated users

Events you'll receive:
• newReport - New report created (sent to everyone)
